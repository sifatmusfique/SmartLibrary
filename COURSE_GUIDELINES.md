# Official CSE 2103 requirements (summary)
Authority: original PDF in references/, pages 1–2. The Group C DOCX defines project scope; this PDF controls grading. Do not edit either original.
- Real-world or game project centered on one or more data structures.
- Group implements core structures; no ready-made STL vector/list/stack/queue/map/set/priority_queue for core storage.
- Each structure supports insertion, deletion, search, update, traversal and applicable empty/full/overflow/underflow/not-found handling.
- State and justify time complexity; report time and space complexity.
- Group size 2–3; GUI optional.
- Submit source, final PDF report, live demo and short presentation; every member explains any code.
- Report: title/objective, problem, structure selection versus alternatives, operations and complexity, system design/flowchart, modules/functions/screenshots, test inputs/outputs and conclusion.
See RUBRIC.md for evidence. No project deadline is established in these sources.
